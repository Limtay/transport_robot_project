# Stage 1 — 로드셀 cnt→N 캘리브레이션 결과 (2026-07-21)

> 트랙션 테스트베드 로드셀(ch0)의 절대력 캘리브레이션. 중력-저울 방식(무게추를 감지축에 중력방향 적재,
> `F = m·g`)으로 cnt↔N 을 확정하고, 선형 유효 구간·포화 한계를 규명했다.
> 인프라: [[testbed_spec]] · 분석 도구: `analysis/traction/loadcell_calib.py`, `traction_analysis.py`.

---

## 1. 최종 결과 (요약)

$$\text{Force[N]} = \frac{\text{cnt} - 214.6}{12.627} \qquad (0.07920\ \text{N/cnt})$$

| 지표 | 값 |
|------|-----|
| **감도 k** | **12.627 cnt/N (= 0.07920 N/cnt)** |
| **offset** | 214.6 cnt (무부하) |
| **선형성 R²** | **0.999988** (46개 측정점, 0~229 N) |
| **피팅 잔차** | std 3.0 cnt = **±0.24 N** |
| **선형 유효 구간** | **0 ~ 229 N (약 23.4 kg)** |
| **하드 포화** | **~247 N (25 kg)에서 ~3234 cnt** — 그 위 무응답 |
| 반복성 (재적재) | 큰추 0.02~0.26 N / 작은추 톨스택 최대 0.89 N |
| 히스테리시스 | 최대 0.17 N (무시 가능) |

확정값은 `analysis/traction/loadcell_cal.json` 에 기록되어 `traction_analysis.py` 가 자동으로 로드셀을
**[N]** 으로 출력한다 (캘리 파일 없으면 raw cnt 로 하위호환).

## 2. 방법

- **방식**: 중력-저울 (무게추를 로드셀 ch0 감지축에 중력방향 누적 적재). ⚠ 수직 근사 — 정밀 셋업 때
  수평(견인) 방향 재캘리 예정. 선형이라 그때 상수만 갱신하면 기존 bag 소급 재분석 가능.
- **무게추**: 10.46, 11.03 kg (대) + 1.53×2, 1.87×2 kg (소).
- **기록**: 브리지 `traction_test_mode`(READ 전용·무모터), `/carrier/testbed/feedback` 200Hz bag.
  각 하중 단계 ≥5초 유지, 안정 plateau 자동 검출 (plateau std ~1.2 cnt).
- **3 사이클**:
  - **c1** (`s1_calwide_c1`): 0→28 kg 광범위 up-down — 포화 한계 탐지.
  - **c2** (`s1_calwide_c2`): 10~21 kg 정밀 up-down — 중범위 채움 + 히스테리시스.
  - **c3** (`s1_callow_c3`): 0~6.8 kg 저범위, **1세트 3회 반복** — 저범위 + 재적재(위치) 반복성.

## 4. 핵심 발견

### 4.1 하드 포화 (~247 N)

로드셀은 **~3234 cnt 에서 하드 포화**한다. 25 / 26.76 / 28.29 / 31.74 kg 이 전부 ~3234 로 붙어(젠틀
롤오프가 아니라 센서·마운트의 물리적 천장), 그 위로는 무게를 더 얹어도 값이 안 오른다. 아래 그림에서
c1 의 정점(4~7단)이 하나로 병합되고, 지난 세션 31.74 kg 점(×)이 천장 위에 있는 것으로 확증된다.

![[stage1_saturation.png]]

### 4.2 위치(재적재) 반복성

3회 재적재 편차가 하중에 따라 커진다 (위 표 마지막 열, 최종 그림 우측 패널). **작은 추를 여러 단
쌓을수록** 스택이 높아져 off-center 로 편차가 커진다 (67 N 에서 0.89 N 피크). 반면 **큰 추는 안정적으로
앉아** 편차가 훨씬 작다 (0.02~0.26 N). ⇒ 이는 **캘리 적재 절차상의 편차**이지 센서 결함이 아니다.
실제 견인력은 자연 힘이므로 무관하다.

### 4.3 경미한 오목성

저범위(≤67 N) 국소 감도 **12.73 cnt/N** 이 전역 **12.63** 보다 ~0.8% 높다. 로드셀이 저하중에서 아주
약간 더 민감하고 고하중으로 갈수록 완만히 둔해지다 247 N 에서 하드 포화한다. 단일 직선 잔차가 ±0.24 N
이라 실용상 무시할 수준.

## 5. 실험에 대한 함의

- **견인력 실험은 힘을 ≤ ~229 N 로 유지해야 한다** (그 위는 로드셀 포화 → 무의미).
- 이론 slope ~20.7 N/A, 데드밴드 ~8 A 기준 → **약 19 A 부근에서 229 N 도달**. 현재 프로파일
  (`std_ramp_cycle` 15 A → ~145 N, `step_probe` 18 A → ~207 N)은 안전 범위 안. **전류 상한을 19 A 이상
  올리지 말 것.** 더 큰 힘이 필요하면 고용량 로드셀 필요.
- 결과 단위는 이제 **[N]** (loadcell_cal.json 반영). 수평 재캘리 시 상수만 갱신하면 기존 bag 소급 재분석.
