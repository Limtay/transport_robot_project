# Current→Traction 히스테리시스 특성화 결과 (2026-07-22, payload 40kg)

> 데이터: 84런 (camp 12 @07-21 + hysteresis_w40 24×3세트 @07-22). 조건: m2 단독, CURRENT 모드,
> ≤14A, payload 40kg, 로드셀 `F=(cnt−214.6)/12.627` [N], 런별 초기 0A hold tare.
> 스크립트: `analysis/traction/hys_{cache,analysis1,analysis2,model,crosscheck}.py` / 캐시 `hys_cache/`.

## 요약 (결론 먼저)

1. **모델 형태 확정**: current→traction 은 **율무관(rate-independent) 이력계**다. 하강분기가 0.3~1.2 A/s
  에서 완전히 겹침(rate간 차 0.9N ≪ 반복산포 2.8N). → **İ(전류 미분) 항 불필요, 반전 이력(방향+반전점
   기억)만 필요**. 유일한 동특성은 빠른 일차지연 **τ63 ≈ 0.15 s** + 미미한 크리프(1~4N/8s).
2. **식의 구조**: F(t) = **이산 Preisach[I(t)]** ∘ (1차지연 τ≈0.15s).
  - 훈련(51런: FORC+하강속도+마이너루프) RMSE **3.5N**, **미학습 파형 검증**(glide/nest/band 21런)
   RMSE **4.9~6.3N = 풀스케일(175N)의 ~3%** (반복성 바닥 1.6% 대비 양호).
  - 가중치는 **NNLS 선형회귀**로 추정 — **데이터 러닝(NN 등) 불필요, 수학적 회귀로 충분**.
  - 모델 파일: `analysis/traction/hys_cache/preisach_model.npz` (릴레이 231개 + bias).
3. **고전 Prandtl-Ishlinskii(play) 는 기각**: 검증 RMSE 12.6~13.3N (2.4배 나쁨). 원인 = 루프 폭이
  진폭뿐 아니라 **작동점에 비례**(아래 4) — PI 의 합동성 가정 위반, Preisach 는 포착.

## 한계 (다음 실험의 근거)

- **PRBS(0.5s 비트) 예측 실패**: 준정적 모델 RMSE 31N → 1차지연 추가 시 17N — 여전히 큼.
**전류 명령이 τ~0.5s 보다 빠르게 변하는 제어에는 현 모델 부족** (느린 slew 제한 명령에는 충분).
- 모델은 **payload 40kg 단일점** — F(I, W) 로 가려면 payload 스윕 필요 (캡스턴 가설: 가중치가 W 에 ~선형).
- 상승 기울기의 rate 의존(~10%)은 크리프로 추정만 — 장시간 hold 실험으로 분리 안 됨.
- 날짜간 bias −2~−6N: 재적재/온도 영향 미분리.
