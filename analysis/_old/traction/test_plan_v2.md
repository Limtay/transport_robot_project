# Traction 정적 실험 2차 계획 — 수식화(모델 동정)용

목표: 방향(상승/하강)을 아는 제어기 전제에서, 포지션을 **무시**한 채
`F = f(I, branch, 상태)` 를 수식으로 만들고 역모델 `I = f⁻¹(F_des)` 를 검증한다.

## 1차 데이터에서 얻은 예비값 (설계 기준점)

| 항목 | 값 | 비고 |
|---|---|---|
| rise 선형 시작점 I_lin | ~9–10 A | 국소 기울기가 ~180 cnt/A로 포화되는 지점 |
| rise 선형 기울기 | ~175–185 cnt/A | 10 A 이상 |
| rise 무릎 구간 | 4–9 A | 기울기 60→145로 상승 (convex) |
| fall 반전 직후 평탄 폭 | ~2–3 A | 피크에서 내려올 때 힘이 잘 안 빠지는 구간 = play(백래시) 폭 후보 |
| fall 기울기 | ~150 cnt/A | 평탄 구간 이후 |
| 1차 지연 τ | 0.2–1.6 s | 랜덤 스텝 검증에서 |
| 포지션 무시 밴드 | ±10–21 % (10 A↑) | 첫 bag 제외, re-tare 기준 |

## 후보 모델 (수식 프레임)

**play(백래시) 연산자 + 구간선형 branch + 1차 지연**:

```
F_ss(I, s) = branch_s(I)          s ∈ {rise, fall}, 전환은 반전 후 Δ [A] 이동 시
τ·dF/dt + F = F_ss                (점탄성 지연)
```

- 1차 데이터의 형상(반전 직후 평탄 → branch 합류)과 일치하고, **역모델이 닫힌 형태**로 나옴 (piezo 제어에서 표준).
- T2/T3 결과가 이 프레임에 안 맞으면(마이너 루프가 피크 이력에 의존) Preisach 로 승급.

## 공통 프로토콜 (모든 세션)

1. **로드셀 캘리브레이션**: 기지 하중(추) 3점 이상으로 counts→N 확보. 세션 시작·종료 2회.
2. **영점 기록**: 트랙-로드셀 **접촉 전** 무부하 5 s → 접촉 후(pre-load 상태) 5 s 녹화.
3. **컨디셔닝**: 트랙 재배치/재장착 후 0→15→0 A 램프 3회 실행 후 폐기 (침하는 첫 램프 중에 진행되므로 사후 보정 불가).
4. **re-tare 창**: 모든 램프/시퀀스 사이 무부하 ≥5 s (파이프라인이 직전 2 s로 재영점).
5. **anchor 램프**: 0.5 A/s 삼각파 0→15→0을 세션 시작·중간·끝에 1회씩 → 세션 내 드리프트 관리도.
6. **포지션 랜덤화**: 포지션을 무시할 것이므로 조건을 포지션에 **블로킹하지 말고 의도적으로 섞는다** (반복 사이에 트랙을 조금씩 굴려 시작 위치를 바꿈). 그래야 최종 ± 밴드에 포지션 산포가 정직하게 포함된다.

## 테스트 매트릭스 (정적)

| ID | 목적 | 파형 | 조건 | 반복 |
|---|---|---|---|---|
| T1 | rate 독립성 | 삼각파 0→15→0 A | dI/dt ∈ {0.25, 0.5, 1, 2, 4} A/s | ×3 |
| T2 | branch의 피크 의존성 | 삼각파 0→I_max→0, 0.5 A/s | I_max ∈ {6, 9, 12, 15} A | ×3 |
| T3 | play 폭 Δ 측정 | 부분 반전: 12→8→12, 15→10→13→6→9→0; 소진폭 ±{0.5,1,2} A 반전 @ 8 A, 12 A | — | ×3 |
| T4 | 지연 τ | 스텝 ±{2, 5, 10} A | 운전점 {5, 8, 12} A 주변, 상/하 방향 | ×3 |
| T5 | 크리프(응력완화) | 정전류 홀드 60 s | {5, 10, 15} A | ×3 |
| T6 | **검증(홀드아웃)** | 랜덤 시퀀스 90–120 s | 진폭·방향 무작위, 2–15 A | ×3 |

- T1이 최우선: 곡선이 rate에 무관하면 "정적 히스테리시스 + τ" 분리가 성립 → 모델이 단순해짐. rate 의존이면 τ가 진폭/rate의 함수인지 T4와 교차 확인.
- T3이 수식화의 핵심 파라미터(Δ)를 준다. 반전 후 힘이 반대 branch에 합류하기까지의 전류 이동량을 직접 측정.
- T6은 **모델 피팅에 절대 사용하지 않는다**. 최종 지표: T6에서 역모델 예측 오차 RMS (사용 구간 9–15 A 기준 목표 ≤ 5–7 %).

## 분석 절차 (파이프라인 확장 순서)

1. branch별 구간선형 피팅 → I_lin 공식 정의: "국소 기울기가 고전류 기울기의 90 %에 도달하는 최소 전류".
2. T2로 branch 불변성 검정(피크별 fall 곡선이 평행이동 없이 겹치는가).
3. T3로 Δ 피팅 → play 모델 조립 → T4의 τ 결합.
4. 역모델 구현: `I = f⁻¹(F_des, branch 상태)` + branch 전환 히스테리시스(채터 방지 데드존 ≥ Δ/2).
5. T6 홀드아웃 검증 → 보장표(전류/힘별 ±2σ, N 단위) 산출.

## 동적 실험으로의 연결

- 회전 중에는 포지션이 연속적으로 섞이므로 포지션 산포는 시간평균화될 것 — 정적 밴드가 상한.
- 정적 모델 확정 후: 속도 {저·중·고} × anchor 램프/스텝/랜덤 최소셋으로 f(I)의 속도 의존만 추가 동정.
- 새 변수: 슬립 상태의 정의와 측정(로드셀 방식 유지 여부) — 정적 결과 확정 후 별도 설계.
