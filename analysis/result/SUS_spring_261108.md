## 5. 정하중 검증 (`s20261108_101607_SUS_test_mass_10.19_10.24`)

무게추를 0 → 10.19 → 20.43(+10.24) → 10.19 → 0 kg 순서로 2회 걸었다. 변위 기준은 §2 시험의 정지 위치(`lin_xy[1]` = 1)다.

| 하중 | 방향 | F [N] (1회 / 2회) | x [mm] (1회 / 2회) | 띠 안 위치 (0=로딩선, 1=언로딩선) |
|---|---|---|---|---|
| 0 | 시작·복귀 | 44.73 / 42.45 / 42.77 | 0.32 / 0.38 / 0.32 | 0.94 / 1.07 / 1.03 |
| 10.19 kg | 올림 | 142.73 / 142.01 | 6.98 / 6.86 | 0.18 / 0.15 |
| 20.43 kg | 정점 | 242.88 / 243.26 | 14.29 / 14.68 | -0.25 / -0.11 |
| 10.19 kg | 내림 | 143.54 / 143.50 | 8.58 / 8.16 | 0.84 / 0.66 |

- **로드셀**: 단계별 힘 변화가 추 무게와 ±0.2 kg(±2 %) 안에서 맞는다.
- **띠 모델 확인**: 올릴 때는 로딩선 근처, 내릴 때는 언로딩선 근처에 멈춘다. §2 마찰 띠 모델이 정하중에서도 성립한다.
- **20.43 kg 정점**: 로딩선보다 0.3~0.6 mm 덜 눌렸다. 정지 마찰이 움직일 때 마찰보다 약간 크다는 뜻으로 본다.
- **정지점 사이 기울기**(12.3~17.4 N/mm)는 띠를 가로지르므로 k로 쓰지 않는다. 같은 쪽 선 위 두 점끼리는
  올림 10.19 → 20.43 kg 13.0~13.7, 내림 10.19 → 0 kg 12.3~12.9 N/mm로 §2보다 5~15 % 크다.
- **F_0**: 0 → 10.19 kg 올림 점을 로딩선 기울기로 연장하면 약 63 N에서 눌리기 시작한다 (서스펜션 무게를 빼면 약 42 N).
  §2의 눌림 시작 힘(81 N, F_0 59.6 N)보다 작다. 손으로 누를 때는 정지 마찰을 넘는 순간이 잡혀서 클 수 있다. 정하중으로 확인하려면 10 kg보다 작은 추가 필요하다.
- **감쇠**: 추를 손으로 천천히 내려 오버슈트가 0.3 mm 이하다. 감쇠는 이 데이터로 추정하지 않는다.
