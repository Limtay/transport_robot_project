# 공유 프로파일 코퍼스 (redesign/05 §3.5)

**C++(`rd_profile.cpp`)과 Python(`analysis/traction/lint_profiles.py`)이 같은 판정을 내리는지**
고정하는 자료다. 두 구현이 갈라지면 lint 를 통과한 프로파일이 실기에서 거부되고,
원인을 찾는 데 시간이 든다 — 그 시간은 대개 실험 준비 중에 든다.

- `ok_*.yaml`     : 양쪽 모두 **수락**해야 한다
- `reject_*.yaml` : 양쪽 모두 **거부**해야 한다 (사유 문구까지 같을 필요는 없다)

판정 근거는 05 §3.3 확정표다. 새 제약을 넣을 때는 **여기에 케이스를 먼저 추가**하고
양쪽 구현을 고친다.
